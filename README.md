# 工途 · 本科专业就业深析

一个覆盖教育部 2026 年本科专业目录的中文职业研究应用。可按学科门类、专业类和具体专业逐级浏览，查看就业方向、岗位工作、五年薪资预测、学历依赖，以及考公、考研、事业编和国企路径。

未来预测模块已更新至 2026 年 8 月：结合国家统计局、教育部、工业和信息化部、国家能源局等公开资料，按具体专业和职业方向生成保守、基准、乐观三种情景，并展示岗位需求、薪资增速、硕士溢价、城市集中度、自动化风险、模型置信度、岗位结构变化和预测反转条件。官方产业数据仅作为模型输入，不直接等同于招聘数量。

应用默认字体已在原设计基础上提高 30%。顶部“字体”按钮支持分别调整导航与顶部栏、专业分类、专业详情和深度报告，范围为 90%—180%；也可以统一调整全部模块或一键恢复默认，选择会自动保存在本机。

首屏采用三级浏览流程：

1. 从哲学、经济学、法学、教育学、文学、历史学、理学、工学、农学、医学、管理学、艺术学和交叉学科中选择学科门类。
2. 选择该门类下的专业类，再选择具体专业。
3. 查看专业类的学科核心、研究或工程对象、主要行业、交叉热点、工作场景和代表性职业集群。
4. 立即查看该专业区别于同大类专业的核心学习对象、行业场景、学历倾向和就业边界。
5. 查看逐专业拆分的就业方向、对应岗位与实际工作内容，以及考公务员、考研、考事业编和进入国企的相对难度与注意事项。
6. 查看可报考岗位类型、研究生方向、事业单位专业技术岗，以及国企类型和岗位示例。
7. 选择学历与城市层级，查看 2026—2030 年税前月薪宽区间预测和学历要求说明。

专业目录现覆盖 13 个学科门类、92 个官方专业类和 883 个本科专业。交叉学科门类没有官方专业类层级，软件额外设置一个“直属专业”展示组。全部专业都可以进入完整长篇深度报告，每个专业至少提供 6 个就业方向、4 条升学体制路径和分学历分城市的五年薪资预测。计算机科学与技术、自动化、电气工程及其自动化、机械设计制造及其自动化保留专家手工数据，其余 879 个专业由具体专业、专业类与学科门类三层画像共同生成并缓存。

## 运行

直接打开 `index.html`，或在当前目录启动任意静态文件服务器。

```powershell
python -m http.server 4173
```

浏览器访问 `http://localhost:4173`。

## Windows 桌面版

```powershell
pnpm install
pnpm run desktop
pnpm run pack
```

桌面版使用 Electron 安全隔离配置：关闭渲染进程 Node.js 能力、启用上下文隔离与 Chromium 沙箱、拒绝网页权限申请、阻止页面跳转，并只允许由系统浏览器打开 HTTPS 外部链接。

安装包和便携版生成到 `release` 目录。代码签名流程见 [SIGNING.md](SIGNING.md)。

## 数据说明

- 当前内置完整目录：883 个本科专业均可生成深度报告；其中 4 个典型工科专业保留专家手工深析。
- 专业地图依据教育部《普通高等学校本科专业目录（2026 年）》整理，覆盖 13 个门类、92 个官方专业类、883 个专业；T 表示特设专业，K 表示国家控制布点专业。
- 每个专业类均有六维画像；交叉学科的 15 个直属专业使用一个仅用于界面浏览的展示组，不计入官方 92 个专业类。
- 就业方向模块按具体专业呈现“方向—岗位—实际工作”三级信息，并明确其与同大类专业的差别；食品质量与安全、城乡规划、遥感科学与技术等跨行业专业也具有独立画像。
- 每个专业包含学历依赖性、考公务员、考事业编、考研和进入国企的相对难度、常见目标及至少 4 条报考或求职注意事项。
- 首屏按专业扩展公务员岗位类型、考研方向、事业编岗位、国企类型与岗位实例，每条路径最多展示 8 个目标；具体资格以当次公告和专业代码为准。
- 五年薪资预测会综合专业类、学历和城市层级调整，属于情景估计，不是招聘报价或收入承诺。
- 薪资为面向职业探索的宽区间估计，会随区域和学历条件调整，不代表任何企业承诺。
- “机会指数”“景气度”与 2026—2030 曲线是研究模型输出，不是官方统计数据。
- 未来预测会综合专业类景气、具体方向差异、毕业生供给、学历门槛、城市集中度和任务自动化风险；预测页面可直接打开最新证据的权威来源。
- 体制内和国企岗位的专业要求每年可能变化，必须以当次职位表、招聘公告和招录单位解释为准。
- 页面底部提供教育部、人社部、工信部、国家统计局等公开来源和针对当前专业的联网搜索入口。
